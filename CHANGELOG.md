# История изменений

Все заметные изменения проекта описываются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.2] — 2026-11-09

### Исправлено
- **`btn:true` снова работает с `scope:any` и `scope:child`.** Проверка
  кнопок выполнялась над самим найденным окном: если правило находило
  текст во внутреннем элементе формы (метка «Вы зарезервированы на
  выполнение задачи»), у метки потомков-кнопок не бывает — и правило
  с галкой «В окне должны быть кнопки» никогда не срабатывало. На живой
  форме это проявлялось так: правило «зарезерв» ловило форму только без
  галки кнопок. Теперь кнопки ищутся у корневой формы (владельца
  найденного окна); для правил `scope:top` поведение не изменилось.
- Текст записи SKIP в журнале уточнён: «у формы нет видимых кнопок».

### Изменено
- **Основное правило** переведено на `scope:any`:
  `rule1=proc:oktell;title:зарезерв;btn:true;scope:any`. Выяснено, что
  строка «Вы зарезервированы на выполнение задачи» — текст внутреннего
  элемента формы, а не заголовка верхнего окна: `scope:top` не находил
  её никогда. С `scope:any` и исправленной проверкой кнопок страховка
  снова активна — окно дозвона без кнопок отсевается само. Пример
  `rule6` (то же слово без проверки кнопок) тоже переведён на
  `scope:any`.

## [1.2.1] — 2026-11-08

### Добавлено
- **Логотип программы** — нарисован по референсу: тёмно-синий скруглённый
  квадрат, оранжевая галочка, белый динамик с дугами звука. Значок теперь
  в трее, в заголовках окон инспектора/диспетчера/редактора и в самом
  файле EXE (`OktellWatch.ico` вшивается при сборке через
  `/win32icon`, размеры 16–256).

### Изменено
- **Основное правило** переведено на универсальное ключевое слово
  `зарезерв` (строка «Вы зарезервированы на выполнение задачи» есть во
  всех задачах обратного звонка): `rule1=proc:oktell;title:зарезерв;btn:true;scope:top`.
  Прежние примеры правил (`перезвон`, `заказ звонка`, `забронир`, `обратн`)
  остались в config.ini закомментированными — на случай обновлений Oktell
  или более тонкой настройки.
- Встроенный в EXE конфиг по умолчанию (создаётся при первом пуске, если
  `config.ini` рядом нет) синхронизирован с боевым `config.ini` — раньше
  он отставал (без `btn:true` и документации исключений).

### Исправлено
- Значок в трее и заголовках окон берётся прямо из вшитого значка EXE
  (`Icon.ExtractAssociatedIcon`), а не рисуется программой отдельно:
  раньше в трее оставался упрощённый рисунок со старой композицией
  (динамик поверх галки), хотя значок файла уже был обновлён. Запасной
  рисунок (для сборки без `/win32icon`) приведён к текущей композиции.

- **Компоновка пакета**: служебные файлы (`config.ini`, `build.bat`,
  `OktellWatch.ico`) переехали в подпапку `system` — рядом с EXE
  остаётся только сама программа. Журнал по умолчанию пишется в
  `system\logs`. При обновлении с 1.2 старый `config.ini` при первом
  старте автоматически копируется в `system\` (оригинал остаётся на
  месте — откат безопасен); журнал у обновлённых установок
  продолжается в прежней папке `logs` (меняется ключом `folder=`
  в `[log]`).

## [1.2] — 2026-11-08

### Добавлено
- **Исключения в правилах** — `title!:`, `proc!:`, `class!:` («не содержит»).
  Правило срабатывает, только если исключающая подстрока **не** найдена
  в окне; хотя бы один обычный признак (без «!») остаётся обязательным.
  Типичный случай: не сигналить об окне дозвона, которое появляется
  после подтверждения обратного звонка —
  `rule1=proc:oktell;title:обратн;title!:дозвон;scope:top`.
  В редакторе правила у каждого поля — галочка «не содержит».
- **Проверка кнопок** — `btn:true` (галочка «В окне должны быть кнопки»
  в редакторе): окна без кнопок — например, окно дозвона, которое
  появляется после подтверждения — игнорируются автоматически:
  оператор не может на них отреагировать. Пропуски фиксируются
  в журнале (SKIP).

### Исправлено
- **Звук больше не доигрывает в эфир.** Как только закрыта последняя
  наблюдаемая форма, сигнал обрывается мгновенно — раньше WAV продолжал
  играть до конца файла, когда оператор уже говорил с клиентом.
  Исчезновение формы теперь замечается по событию закрытия окна
  (`EVENT_OBJECT_DESTROY`) — без ожидания ближайшего страховочного опроса.
  Пауза наблюдения тоже глушит играющий звук.
- **Редактор правила:** подписи полей больше не налезают на поля ввода —
  подпись теперь расположена над полем, поля ввода расширены во всю ширину
  формы, высота формы рассчитывается по содержимому (не зависит от DPI).
- Примеры («например: oktell», «например: перезвон») показываются внутри
  пустых полей и исчезают при начале ввода — подсказки видны и не мешают.

### Изменено
- Метаданные сборки заполнены полностью (описание, компания, копирайт,
  версии файла и продукта), внутреннее имя EXE приведено к `OktellWatch` —
  в свойствах файла программа теперь представляется корректно. Это влияет
  и на доверие антивирусов к неподписанному бинарнику.
- Примеры правил в config.ini дополнены под реальные названия задач
  обратного звонка: «перезвон…», «заказ звонка», окно
  «Вы забронированы для выполнения задачи».

## [1.1] — 2026-11-01

### Добавлено
- **Мгновенное обнаружение** показа новых окон по событиям Windows
  (`SetWinEventHook`, `EVENT_OBJECT_SHOW`) с троттлингом; страховочный
  полный опрос всех окон теперь выполняется не чаще раза в 15 секунд —
  расход ресурсов в простое сведён к нулю.
- **Диспетчер правил** (меню значка): список правил с галочками,
  добавление / изменение / удаление без правки `config.ini`, столбец
  «Окон сейчас» и вкладка «Окна в работе». Отключённое правило хранится
  в конфиге с пометкой `off:true`.
- **Редактор правил** с понятными полями (процесс, заголовок, класс,
  где искать) — синтаксис помнить не нужно.
- Сортировка списка окон в инспекторе кликом по заголовку столбца.
- Клавиши в диспетчере: `F2` — изменить, `Delete` — удалить.

### Изменено
- Инспектор обновляется плавно: строки добавляются/изменяются по одной
  (diff-обновление), двойная буферизация списка, «тихие» тики, если
  ничего не изменилось — окно больше не мигает.
- Кэш имён процессов с временем жизни (`procCacheSec`) вместо пересоздания
  списка процессов на каждом опросе.

## [1.0] — первая версия

- Слежение за окнами по правилам `proc:` / `title:` / `class:` / `scope:`
  (подстроки без учёта регистра, поля через И, правила через ИЛИ).
- Оповещение: звук (WAV или системный) с повтором каждые N секунд,
  поднятие окна наверх, мигание кнопки на панели задач.
- Инспектор окон со списком всех окон и режимом захвата
  «Окно под курсором» (выбор — `Ctrl+Пробел`, клик проходит насквозь).
- Конфиг `config.ini` с горячей перезагрузкой, журнал `logs\`,
  автозапуск с Windows, пауза наблюдения, защита от второго запуска.
- Один файл исходников, сборка штатным `csc.exe` без SDK (build.bat).
